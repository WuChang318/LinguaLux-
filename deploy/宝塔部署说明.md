# 宝塔部署说明（无框架纯 PHP 版）

本项目后端为纯 PHP（无框架、无 Composer），前端为纯静态 SPA（无 Node、无构建），
上传到宝塔即可运行。下面是完整步骤。

## 0. 环境要求
- 宝塔面板已安装 Nginx（或 Apache）+ PHP（**7.4 及以上，推荐 8.0+**）+ MySQL。
- PHP 需启用扩展：`pdo_mysql`、`curl`、`mbstring`、`openssl`、`json`（宝塔默认基本都带，检查一下即可）。

## 1. 上传代码
把整个 `backend/` 目录里的内容上传到你的站点目录，例如：
```
/www/wwwroot/你的域名/
├── public/        ← 站点运行目录（index.php + index.html + assets/）
├── src/           ← PHP 后端代码
├── config/        ← 配置（含 .env）
└── database/      ← 建表 SQL
```
（即：把 `backend` 里的 `public`、`src`、`config`、`database` 四个目录上传上去。）

## 2. 设置运行目录
宝塔 → 网站 → 你的站点 → **设置 → 网站目录 → 运行目录**，选择 **`/public`**。

## 3. 设置伪静态
宝塔 → 网站 → 你的站点 → **设置 → 伪静态**，粘贴：
```
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```
（如果用 Apache，直接保留 `public/.htaccess` 即可，无需额外设置。）

## 4. 创建并导入数据库
1. 宝塔 → **数据库 → 添加数据库**，记下「数据库名 / 用户名 / 密码」。
2. 打开该数据库 → **导入** → 上传 `backend/database/schema.sql` 并执行。

## 5. 修改数据库配置
编辑站点里的 `config/.env`，改成你第 4 步创建的库：
```
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=你的数据库名
DB_USER=你的数据库用户名
DB_PASS=你的数据库密码
```

## 6. 访问
浏览器打开你的域名。**第一个注册的账号会自动成为管理员**（拥有"管理"入口，用于处理举报/下架）。

## 7. 常见问题
- **页面 500 / 数据库连接失败**：检查 `.env` 的库名/账号/密码，以及 PHP 是否启用了 `pdo_mysql`。
- **自动填充（音标/释义）没反应**：检查 PHP 的 `curl` 扩展是否启用；免费 API 偶尔限流，稍后再试或手动填写。
- **听写没声音**：单词无音频时用浏览器内置朗读，需要浏览器支持 TTS（Chrome/Edge 均可）。
- **改了前端或后端**：直接覆盖对应文件即可，无需任何构建/重启。

## 附：自动填充 API 说明
- **（可选，推荐）DeepSeek**：在 `config/.env` 填 `DEEPSEEK_API_KEY` 即启用，词库页支持「✨ 一键填充」批量补齐；不填则用下面的免费 API，单条「自动填充」仍可用。
- 音标/发音/英文释义/例句：Free Dictionary API（`api.dictionaryapi.dev`），免 key。
- 中文释义：MyMemory（`api.mymemory.translated.net`），免 key，匿名约 5000 字符/天；量大可去官网填邮箱提升额度。
